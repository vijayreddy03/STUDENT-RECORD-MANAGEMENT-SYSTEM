Today, I am uploading my mini project to GitHub titled:

“Student Record Management System (SRMS)”

This project is developed using C programming and is designed to manage student information digitally, replacing traditional paper-based record maintenance.

In this project, I have implemented the following main features:

Login system using username and password stored in a file

Role-based access for Admin, Staff, and Guest

Adding new student records

Displaying all student records

Searching students by roll number

Updating existing student details

Deleting student records


The project uses file handling with two main files:

credentials.txt — for storing login details

students.txt — for managing all student data


I used modular programming concepts by separating the code into meaningful functions such as:
loginSystem(), addStudent(), searchStudent(), updateStudent(), deleteStudent(), etc.

This project helped me understand and implement:

File handling in C

Structure usage

Role-based access control

Real-time data management using text files
